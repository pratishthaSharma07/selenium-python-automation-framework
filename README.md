Selenium Python Automation Framework

This project is an end-to-end automation framework built using Selenium, Python, and Pytest following the Page Object Model (POM) design pattern.

Features
- Signup Automation
- Login & Logout Flow
- Invalid Login Validation
- Account Creation Flow
- Explicit Wait Handling
- HTML Reporting with Pytest

Tech Stack
- Python
- Selenium WebDriver
- Pytest
- Page Object Model (POM)

Project Structure
- pages/ → Page classes
- tests/ → Test cases
- utils/ → Utility functions
- reports/ → Test reports


How to Run
```bash
pytest -v --html=reports/report.html --self-contained-html
